How it works

Hybrid retrieval combines TF-IDF (term similarity) and BM25 (keyword matching) with Reciprocal Rank Fusion. Every answer cites its source chunks, and citation verification flags ungrounded claims before they reach the user.

· Zero ML dependencies — runs on Python stdlib + FastAPI
· Deterministic — same query always returns same answer
· CI gate fails when pass rate drops below 90%
